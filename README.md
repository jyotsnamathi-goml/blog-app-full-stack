# blog_full-stack

This is a Next.js project bootstrapped with `create-next-app`.

It is a simple blog application built as part of a hands-on lab.

## Features

- **Next.js & TypeScript**: Modern frontend stack.
- **App Router**: Using layout structure and modern patterns.
- **Local JSON Data**: Blog posts loaded from a local JSON dataset.
- **SSG (Static Site Generation)**: The home page is statically generated.
- **SSR (Server-Side Rendering)**: Individual dynamic blog post pages are rendered server-side.
- **Dynamic Routes**: Uses `[slug]` routing.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
